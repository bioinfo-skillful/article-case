Send the opening through native **Plan first** and verify the actual persisted intent. Handle real scope questions within allocated authority. Preserve the full first Plan/version before feedback. If recovery is needed, retain the failure first, check native correction is settled, and use only the allocated assistance and remaining budget.

When authorized, select a useful artifact and freeze its native Reproduction target/scope/comparisons. Capture preview and actual execution evidence. End with [02](02_Post_Run_Collection.md), reporting science, feature observations and replay consistency separately.

## Conditional follow-up examples

- If stage-related survival differences are supported, ask which available baseline factors merit a bounded adjusted investigation.
- If follow-up or model assumptions limit interpretation, discuss an alternative summary justified by the observed limitation.
- If missing stage or outcome data affect applicability, ask what the selected cohort represents and whether a sensitivity analysis is feasible.
- If the first answer is sufficient, accept it and consider native Reproduction of a suitable output instead of requiring another model.

These are examples, not a mandatory sequence or hidden output requirements. Choose based on actual findings and a recorded decision. Preserve all failed attempts; on finalization/revision conflict use only the allocated new-session allowance. Preparation alone does not start a run or prove any product capability.
