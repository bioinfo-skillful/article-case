## Track each stage

Record case/protocol/attempt/stage, project/session/run IDs, native task/message lineage, actual initial prompt, Plan versions and decisions, question/estimand, approved methods and assumptions, promised output contents, prospective checks/claim slots and freeze time. Use timestamps with time zones.

## Keep these checkpoints visible

- [ ] CP0: authority, budget, settings, input and capture readiness recorded.
- [ ] CP1: native Plan-first intent, initial assessment, feedback chain and exact-version approval verified; stage checks frozen before results.
- [ ] CP2/CP3, repeating: inputs/runs/artifacts and every observed review/correction retained; visible questions accounted for.
- [ ] Recovery/extension: failure or stage outcome retained; activity settled; authority/limits checked; actual prompt and attribution saved.
- [ ] CP4: execution and review/correction terminal states checked; final versions and independent science assessment frozen.
- [ ] CP5/CP6: authorized target and preview retained, actual native replay collected, or explicit non-execution/gap recorded.
- [ ] CP7: all attempts, interventions, missing evidence, reporting categories and acceptance/display decisions accounted for.

Maintain a handoff with current states, pending questions/decisions, recent saved screenshots and hashes, remaining budget/allowances, omissions and the next authorized action. Refresh native state after resuming; an old handoff does not establish current execution status.
