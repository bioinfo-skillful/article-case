# Collect and assess: Smoking and depressive symptoms in NHANES

Protocol **nhanes-smoking-phq9-conversation-v2.1.1**. External operator material; do not submit this document to the scientific agent or built-in Reviewer.

Use retained evidence and the [collection matrix](design-basis/evidence-collection.md). Collection cannot recreate an unretained initial Plan, transient screenshot, old artifact version or unobserved review scope.

1. Read the handoff and re-query execution, review, correction and visible questions. Record terminal/partial/blocked status and what remains active. Freeze stable versions before assessment.
2. Inventory all attempts/stages, settings, opening/attachments, decision allocations, exact-version Plan approvals and assistance. Keep original failed outcomes alongside subsequent recovery.
3. Check actual source inputs and Notebook execution; map native input → run → artifact versions. Mark H-built relationships as external organization, not product-captured provenance. Check artifact publication/preview states separately from physical file existence.
4. Apply the stage's prospective checks from [04](04_Checklist_Alignment_and_Evaluation.md) and its approved assessment contract. Validate the independent reference, preserve comparison details and disclose shared dependencies. Do not enforce methods or output quotas from an older protocol.
5. Assess each available native review's finding validity, scope, version binding and actual repair/re-execution/re-review chain. Preserve native verdicts even where external checking disagrees or scope is insufficient. Distinguish no observed reads from failed reads.
6. For Reproduction, collect preview, declared scope, locks/gaps, receipt or failure, logs and per-output comparison states/real new bytes. Record not-run, unavailable, not-generated and not-retained states honestly.
7. Complete every reporting category in the [section 8.2 mapping](design-basis/checklist-alignment.md), with evidence/source labels or an applicability reason. Account for all attempts, decisions, gaps, timing, interventions and display choices.

## Separate conclusions

| Dimension | Decision and limits to record |
|---|---|
| Research usefulness | Answered / partially answered / unanswered for the agreed question, with evidence |
| Scientific validity | Pass within checked scope / fail / incomparable / not evaluated / insufficient evidence; retain unresolved layers |
| Product-feature evidence | Observed operation and exact coverage for Plan, Notebook/provenance, artifacts and Reviewer; no inference from scientific success alone |
| Reproduction consistency | Actual native outcome, declared process, comparison levels, help and unobserved limits; no implication of correctness |

Do not combine these into one score. A confirmed scientific error is retained even if review or replay passes. Present the concrete assessment to the allocated acceptance owner. Publish or export run evidence only under separate authorization; this repository contains preparation materials.
