## Directory guide

Use CP0-setup for settings and inputs at submission; CP1-plan for versions and decisions; CP2-execution for actual inputs, Notebook records and provenance; CP3-review for each native review/correction; CP1-plan for the prospective assessment contract and CP4-assessment for independent checks; CP5-reproduction-preview for target/preview/locks, CP6-reproduction-execution for actual replay evidence or non-execution, and CP7-archive for checkpoint summaries and validation; deliverables for original scientific outputs; logs for native log snapshots.

REPORT.md separates the four outcome dimensions. HANDOFF.md describes current state and next action. evidence-index.jsonl and interventions.jsonl are append-only records; manifest.json inventories bytes and accounts for required collection categories per stage. Its own hash is excluded.
