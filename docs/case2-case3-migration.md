# Case2 and Case3: conversational preparation

Prepared 2026-09-16 under framework 2.0.0. Both new protocols are **prepared, not live-validated**. NHANES repeat attempts 2 and 3 are deferred; this preparation does not consume or renew a run budget. No cases are launched and no repository publication is authorized by this update.

## Identity and history

Case2 is [longitudinal COVID-19 proteomics](../cases/covid-haemodialysis-proteomics/START_Run_Case_with_Codex.md), not GBM. Case3 is [TCGA kidney-cancer survival](../cases/tcga-kirc-stage-survival/START_Run_Case_with_Codex.md). Existing NHANES and GBM preparations and the immutable archive remain unchanged.

The previous Case2 preparation was identified inside a historical user-supplied results bundle; only its frozen prompt and source metadata informed this migration. No run records, historical scientific outputs, numerical reference answers or reconstructed input dictionary were imported. Its original two public CSV identities were independently checked against freshly retrieved upstream bytes. Case3's previous preparation and source-readiness record supplied its study locator; current retrieval independently confirmed file identity. Original local materials remain untouched. New protocol IDs prevent treating future runs as fixed-prompt repeats of those historical cases.

## What changes

| Area | Prior prescription | New conversation |
|---|---|---|
| Case2 | Fixed early/late windows, pairing rules, t-tests, assay thresholds and 15 outputs | Longitudinal change and sampling-time concern; agent justifies design and useful outputs |
| Case3 | Fixed stage dichotomy, 60/36-month horizons, Python implementation, Cox details and 13 output groups | Retrospective stage-survival question; agent justifies representation, estimand, follow-up and methods |
| Approval | Detailed method choices inherited from preparation | Exact native Plan version establishes stage commitments |
| Evaluation | Predetermined methods/output inventory | Scientific validity principles first; detailed checks frozen after Plan selection and before estimates |
| Progress | Compulsory analysis sequence | Conditional questions after execution and relevant review settle |

The approved openings are preserved verbatim in 01. Actual attachments and source locators are described separately in source instructions. Both packages require English communication and outputs through launch context. Source pinning establishes identifiable inputs, not a preferred answer. Reasonable alternative methods are valid when justified; this does not excuse unsupported scientific claims or failure to deliver approved commitments.
